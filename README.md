# Integration-Confinamiento-Electromagn-tico-Hibrido
Simulación MATLAB de confinamiento de partículas cargadas en un reactor toroidal. Integra fuerzas eléctricas (Coulomb), magnéticas (Larmor) y control activo basado en Ampère/Biot-Savart, permitiendo comparar Euler, RK2 y RK4 mediante una visualización interactiva en tiempo real.
